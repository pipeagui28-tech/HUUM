Solución Tecnológica

HUM: The Noise Nobody Hears

¿En qué consiste el proyecto?

Nuestra solución tecnológica integra una plataforma web interactiva creada como soporte narrativo y espacio de lectura para el cómic digital HUM.

Combina maquetación web con ilustración y diseño gráfico estilo cómic para representar de forma visual el sobrepensamiento y las inquietudes emocionales de los jóvenes.

LEER CÓMIC (PDF)

Plataforma Web

Funciona como espacio centralizado para documentar el proceso, la identidad visual y conectar la narrativa gráfica con los lectores.

Narrativa Gráfica

Estética orgánica estilo boceto que refleja la imperfección y la constante tormenta de ideas del "ruido mental".

"El ruido no define quién eres, sino cómo aprendes a escuchar tu propia voz."
